C. Yet Another Black Cell Problem
time limit per test2 seconds
memory limit per test256 megabytes

Inspired by this problem.

There is a strip divided into cells numbered from 0
 to 109
 from left to right. Initially, all cells are white.

An array a
 of length n
 is given, containing the indices of n
 cells. We want to paint all these n
 cells black.

Given an integer x
, you may choose an integer y
 such that 0≤y≤x
, and then arbitrarily select y
 cells that are not in a
. We also want to paint these selected y
 cells black while keeping all non-selected cells white.

You may perform the following operation any number of times:

Choose two distinct cells i
 and j
 such that 1≤|i−j|≤k
, and paint them black, regardless of whether they were originally black or white.
Find the minimum value of k
 for which it is possible to paint all the required cells black while keeping other cells white.

Input
Each test contains multiple test cases. The first line contains the number of test cases t
 (1≤t≤104
). The description of the test cases follows.

The first line of each test case contains two integers n
 and x
 (2≤n≤2⋅105,0≤x≤n
).

The second line contains n
 integers a1,a2,…,an
 (0≤ai≤109
). It is guaranteed that ai<ai+1
 for all 1≤i<n
.

It is guaranteed that the sum of n
 over all test cases does not exceed 2⋅105
.

Output
For each test case, print a single integer — the minimum value of k
 for which it is possible to paint all the required cells black while keeping other cells white.

Example
InputCopy
4
2 0
1 3
2 1
1 3
3 1
2 5 7
10 2
0 6 8 10 13 14 16 19 25 31
OutputCopy
2
1
2
3
Note
In the first example, we cannot paint any cell other than 1
 and 3
 black because x=0
. So it's optimal to set k=2
 and choose i=1,j=3
 in the first operation.

In the second example, we can set k=1
, which is the minimal available value. We first choose i=1,j=2
 to paint and then choose i=2,j=3
 to paint. After that, cells 1,2,3
 are painted black, only cell 2
 is not in the given list, which satisfies the condition x=1
.
